# Salsa20/12 – Phần thực hiện cá nhân
- Họ tên: Nguyễn Trung Hiếu - 20233399
## Phần phụ trách
1. Cài đặt hàm rotl32() và quarterround().
2. Xây dựng các kiểm thử cho phép xoay bit và Quarter Round.
3. Xây dựng chương trình demo src/main.c, kết hợp các module của nhóm để minh họa mã hóa, giải mã và kiểm tra kết quả.
## Các file
- `src/quarterround.c`: mã nguồn hai hàm.
- `tests/test_quarterround.c`: chương trình kiểm thử.
- `include/salsa20.h`: header dùng chung của nhóm.
- `src/main.c`: chương trình demo mã hóa, giải mã và kiểm tra kết quả.
